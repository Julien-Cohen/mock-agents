# A2A Python Mock Evaluators

This directory contains runnable examples demonstrating how to build and interact with an A2A-compliant agent using the Python SDK.

```bash
docker build . -t mock-true-semantic-validator:latest
```


```bash
docker run -p 9000:9000 -p 50071:50071 mock-true-validator:latest
```



**Run:**

```bash
uv run python true_agent_9000.py
```
